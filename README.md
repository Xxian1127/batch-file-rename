# 文件批量重命名工具（交互版）
Python脚本，批量对文件夹内文件重命名，自动编号。

## 功能
1. 输入文件夹路径
2. 自定义文件名前缀
3. 文件自动按顺序编号：图片01、图片02...

## 使用方法
1. 电脑安装Python环境
2. 终端运行：python rename.py
3. 根据提示输入文件夹路径和文件前缀

## ⚠️注意事项
- 测试请先用无关文件，避免重要资料改名出错
- 本工具仅本地文件处理，不做任何游戏修改、外挂相关功能


简单版
全程按提示问答：
请输入文件夹路径：D:/照片        ← 填你想改名的文件夹（文件夹路径复制方法为 对目标文件夹输入ctrl+shift+c）
请选择模式（1=序号 2=替换）：1     ← 想按照1、2、3编号就输1
输入文件名前缀：img              ← 前缀随便填，如 img
输入起始编号：1
脚本会先列出所有将改名的文件，确认无误后输 y 回车，就全改完了。
